### Comandos Git

`git commit`: Salva as alterações realizadas dentro do código no histórico.

`git branch`: Criação de novas ramificações a partir da ramificação em que se está

`git checkout`: Navegar entre branches

`git status`: Mostra o estado dos arquivos modificados

`git add`: Prepara os arquivos alterados para o envio

`git pull`: Baixa as atualizações remotas

`git push`: Envia os commits para o servidor remoto

`git clone`: Copia um repositório remoto

`git init`: Inicia um repositório local

`git merge`:  Juntar duas branches

`git rebase`: Juntar duas branches de forma linear e mais organizada

### Diferenças entre Git e Github

Git é a ferramenta local que rastreia as mudanças no código e o github é uma plataforma na nuvem que hospeda esses projetos gerenciados pelo git.
