# Resumo conceitos iniciais de Git e Github
## repositório
```bash
Lugar onde se armazenam pastas e arquivos 
```
## branch 
```bash
É uma versão paralela de seu repositório, usada para que a main não seja constantemente alterada
```
## commit
```bash
É uma mudança realizada em um arquivo ou pasta sua
```
## pull request
```bash
É uma solicitação de mudança, quando você faz alterações e sente que pode alterar sua main sem problema 
```
## merge
```bash
Adiiona a sua solicitação de pull request para a main
```
## rebase 
```bash
Pega os commits da sua branch e os reaplica no topo de outra, reescrevendo o histórico de forma linear
```
## revert
```bash
Cria um novo commit que desfaz as alterações de um commit passado sem apagar o histórico
```
## reset
```bash
Move o estado atual do repositório para um commit anterior, podendo descartar ou manter as alterações no seu código
```
## HEAD
```bash
Ponteiro que indica onde você está no repositório no momento (a branch ou o commit atual)
```
## checkout
```bash
Usado para navegar entre diferentes branches ou restaurar arquivos para um estado anterior
```
## cherry pick
```bash
Copia e aplica um commit específico de qualquer branch para a sua branch atual
```
