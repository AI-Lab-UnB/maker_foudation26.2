# Resumo de aprendizados da semana 1
Nesta semana eu aprendi o que é o GitHub e os comandos de Git, nesse resumo, vou explicar tudo o que entendi e o que aprendi sobre Git e GitHub.
## O que é Git?
O Git é um software instalado em nossos computadores que monitora localmente (offline) todas as alterações, sendo elas:
- *Commits*: Basicamente um checkpoint/save para não perder o progresso do codigo/produto;
- *Branchs*: É como uma linha do tempo alternativa da main, serve para testarmos mudanças/funcionalidades novas sem estragar o projeto principal, a *main*;
- *Merge*: É auto explicativo, é a fusão da mudança nova com a *main*. Se a mudança deu certo, fazemos o *merge* para unir elas no projeto principal;
## O que é GitHub?
O GitHub é uma plataforma de hospedagem na nuvem que serve para compartilhar codigos, revisar e colaborar com seus colegas de equipe, nele existe e pode-se fazer:
- Repositório remoto: É a pasta do projeto guardada na nuvem;
- *Push*: Envia os *checkpoints* (os *commits*) salvos no seu computador para o GitHub;
- *Pull*: "Puxa" as novidades que outras pessoas enviaram para o projeto na nuvem para o seu computador.
- *Pull Request/PR*: É pedir permissão para o ADM do projeto revisar as alterações (como vai acontecer assim que eu commitar esse markdown) antes de junta-las (isso não vai acontecer porque pediram pra deixar o PR em aberto)
