# Resumo Semana 1

### Github e Git

O Git é uma ferramenta que existe para acompanhar as versões de um código, o Github é a principal plataforma para armazenar esses repositórios, além de permitir a colaboração de outras pessoas nos projetos.

### Conceitos e comandos fundamentais

*Repositório:* É onde o git armazena arquivos do projeto, e o histórico das alterações feitas.

*Branch:* Linha independente do desenvolvimento. Pode fazer alterações sem modificar diretamente a branch principal.

*Commit:* Registro de alterações realizadas no projeto. Ele possui uma mensagem que descreve qual foi a alteração feita.

*Staging Area:* A Staging Area é uma área intermediária do Git onde você coloca as alterações que quer incluir no próximo commit.

*Pull Request:* Solicitação para que as alterações feitas em uma branch sejam revisadas.

git init — Cria um novo repositório.

git clone — Copia um repositório para o computador.

git status — Mostra o estado atual do repositório.

git add — Adiciona alterações à Staging Area.

git commit — Registra as alterações no histórico.

git push — Envia commits locais para o repositório remoto.

git pull — Busca e integra alterações do repositório remoto.

git fetch — Busca informações do repositório sem integrar as alterações a branch atual.

git branch — Lista ou cria branches.

git switch — Muda de branch.

git merge — Combina alterações de uma branch com outra.

git log — Mostra o histórico de commits.
