## Learn Git Branch

No site consegui aprender alguns conceitos que são usados recorrentemente no github, deixo aqui embaixo o significado de alguns:

**Git** é uma ferramenta de controle de versão que permite registrar, organizar e recuperar alterações em um projeto.

**GitHub** é uma plataforma online que hospeda repositórios Git e oferece ferramentas para colaboração, como Pull Requests, Issues e Code Review.

### Commit

Um commit registra as alterações feitas no projeto em um determinado momento. É como criar uma "versão" do código.

### Branch

Uma branch é uma ramificação do projeto que permite desenvolver uma funcionalidade ou fazer alterações sem modificar diretamente a branch principal.

### Merge

O merge serve para juntar as alterações de uma branch em outra.

### Checkout

O checkout permite trocar de branch ou acessar uma versão específica do projeto.

### Rebase

O rebase reorganiza o histórico de commits, colocando os commits de uma branch sobre a versão mais recente de outra branch.
