# Conteúdo Estudado — GitHub Skills
Objetivo

O objetivo desta atividade foi aprender os conceitos básicos de colaboração utilizando o GitHub,  por meio das trilhas Introduction to GitHub e Communicate using Markdown.

## 1. Introduction to GitHub

Durante a trilha Introduction to GitHub, foram estudados alguns conceitos relacionados ao funcionamento do GitHub e ao trabalho colaborativo em projetos.

Principais conteúdos aprendidos
- Repositórios: local onde ficam armazenados os arquivos e o histórico de um projeto.
- Branches: permitem criar uma linha de desenvolvimento separada da principal, possibilitando trabalhar em novas funcionalidades ou alterações sem modificar diretamente a branch principal.
- Commits: registram alterações realizadas nos arquivos do projeto, criando um histórico do desenvolvimento.
- Pull Requests (PRs): permitem propor alterações feitas em uma branch para que sejam analisadas e, posteriormente, incorporadas ao projeto.
- Issues: utilizadas para registrar tarefas, problemas, sugestões e outros assuntos relacionados ao projeto.
- Colaboração: o GitHub permite que várias pessoas trabalhem no mesmo projeto utilizando branches, commits e Pull Requests.

## 2. Communicate using Markdown

Na trilha Communicate using Markdown, foi estudado o uso da linguagem Markdown para formatar textos no GitHub.

Neste curso, eu aprendi e pratiquei:

- Adicionar headers (títulos) em um arquivo Markdown;
- Adicionar uma imagem;
- Adicionar exemplos de código;
- Criar uma lista de tarefas (task list);
- Fazer o merge de um Pull Request.


Conteúdos aprendidos:

- Criação de títulos utilizando #.
- Utilização de negrito e itálico.
- Criação de listas numeradas e não numeradas.
- Criação de links.
- Inclusão de trechos de código.
- Utilização de blocos de código.
- Organização de documentos utilizando diferentes níveis de títulos.
- Utilização de Markdown para melhorar a comunicação em Issues, Pull Requests e arquivos README.md.

## 3. Aplicação prática

Após estudar as trilhas, os conhecimentos foram aplicados no repositório da atividade.

O fluxo utilizado foi:

1. Criar uma branch própria para realizar o trabalho.
2. Fazer as alterações necessárias.
3. Registrar o trabalho por meio de commits.
4. Enviar a branch para o GitHub.
5. Criar um Pull Request.
6. Manter o Pull Request atualizado e verificar possíveis conflitos.
