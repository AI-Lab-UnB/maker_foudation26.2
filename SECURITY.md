# Security Policy

## Supported Versions

Since this is an educational repository for student assignments, there are no specific version releases. Security updates are applied directly to the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security vulnerabilities or have security-related concerns about this repository, please do not open a public issue.

Instead, please report it privately to the project administrators or the AI Lab — UnB staff. 

We will try to address the issue as soon as possible.
