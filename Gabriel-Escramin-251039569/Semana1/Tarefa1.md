## O que é o Github?
É uma plataforma de hospedagem de código-fonte baseada em nuvem que utiliza o sistema de controle de versão Git. Ele funciona como um espaço de trabalho colaborativo que permite gerenciar, rastrear e desenvolver software em projetos, de forma integrada e segura.

## Comandos principais do Github:

+  `git status `: Mostra o estado atual dos arquivos 
+ `git add . `: Prepara os arquivos modificados para serem salvos
+ `git commit -m `: Salva as alteraçoes preparadas no historico local
+ `git push `: Envia os commits locais salvos para o repositorio no Github
+ `git pull `: Baixa e mescla as atualizaçoes mais recentes do repositorio para o computador
+ `git branch `: Lista,cria ou deleta projetos
+ `git merge `: Junta o historico de uma ramificaçao na ramificaçao atual
