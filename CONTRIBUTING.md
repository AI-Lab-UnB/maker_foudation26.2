# Contribuindo para o Makers Foundation 26.2

Agradecemos o seu interesse em contribuir! Este repositório é destinado às entregas semanais dos alunos do programa **Makers Foundation 26.2** do AI Lab — UnB.

## 🚀 Como enviar suas entregas

Siga o fluxo abaixo para adicionar suas atividades ao repositório:

1. **Crie sua branch**
   A partir da branch `main`, crie uma branch com o seu nome (ex: `joao-silva`).
   ```bash
   git checkout main
   git pull origin main
   git checkout -b seu-nome
   ```

2. **Organize seus arquivos**
   As entregas devem ser colocadas dentro da sua pasta pessoal (ex: `Nome_Aluno_Matricula/`).
   Siga a estrutura de pastas por semana:
   ```
   Nome_Aluno_Matricula/
   ├── Semana_01/
   │   └── Atividade1.md
   ├── Semana_02/
   │   └── Atividade1.pdf
   ```

3. **Faça commits claros**
   Adicione os arquivos e faça um commit com uma mensagem descritiva.
   ```bash
   git add .
   git commit -m "feat: Adicionada atividade 1 da semana 1"
   ```

4. **Abra um Pull Request (PR)**
   Faça o push da sua branch e abra um PR no GitHub apontando para a `main`.
   ```bash
   git push origin seu-nome
   ```
   Preencha o template de Pull Request fornecendo as informações necessárias sobre a sua entrega.

## 📝 Regras Gerais

- Não altere os arquivos de outros colegas sem autorização.
- Certifique-se de que não está enviando arquivos muito pesados ou desnecessários (como pastas `node_modules`, `.env`, etc.).
- Qualquer dúvida, procure os monitores ou professores do projeto.

Obrigado por fazer parte do Makers Foundation!
