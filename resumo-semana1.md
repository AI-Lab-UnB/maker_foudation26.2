# Resumo da Semana 1 - Maria Luisa

## 🎯 Objetivo da Semana
A primeira semana do projeto de extensão teve como foco o nivelamento e a prática das ferramentas essenciais de versionamento de código e documentação utilizando o Git e GitHub.

## 📚 Tópicos Estudados

* **Learn Git Branching:** Utilização da plataforma interativa para compreender de forma visual o funcionamento da árvore do Git. Praticamos comandos fundamentais como criação de branches, commits, merges e navegação pelo histórico do repositório.
* **Introduction to GitHub:** Conclusão da trilha inicial do GitHub Skills. O módulo abordou a estrutura básica da plataforma, a relação entre repositórios locais e remotos, e o fluxo de trabalho colaborativo.
* **Communicate using Markdown:** Estudo das formatações textuais através do GitHub Skills. A prática envolveu a estruturação de cabeçalhos, listas, links e ênfases, garantindo uma documentação padronizada (formato utilizado, inclusive, para a criação deste próprio resumo).

## 🚧 Principais Aprendizados

* A visualização gráfica do jogo facilita o entendimento de como as branches se dividem e se unem sem quebrar o código principal.
* O uso correto do Markdown é indispensável para organizar ideias e manter o repositório bem documentado.

## ⏭️ Próximos Passos

* Aplicar os comandos de Git e a formatação Markdown diretamente nas próximas tarefas práticas e entregas do projeto.
